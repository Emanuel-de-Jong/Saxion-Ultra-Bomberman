# Ultra Bomberman
For the class: 1.2 Project IT's in the Game

A bomberman game for a school project and to learn Unity. Out of passion, I also made an AI using RL afterwards to have computer opponents.

Playable with up to 4 players.

> [!NOTE]
> The `main` branch is the playable version of the game. The `machine-learning` branch has the latest code for training a PPO model, including visual training optimizations.

**Active Development:** 2020-11-15 - 2021-02-19<br>
